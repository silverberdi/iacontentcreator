## Business Intent

Estefania exists to become the project's primary AI influencer.

Her business objective is to generate organic, consistent public lifestyle content that builds audience affinity, proves visual and narrative appeal, and attracts brands interested in collaborations, campaigns, sponsored content, or paid usage.

Business model:

```text
audience -> affinity -> brand interest -> collaborations / campaigns / sales
```

Estefania should not be optimized as GFE, BFE, or authority content.

### Success Signals

- Organic audience growth.
- Saves, shares, and comments on lifestyle content.
- Direct messages showing affinity.
- Visual recognizability across scenes.
- Positive response to soft product placement.
- Inbound brand interest.
- Repeatable production of brand-safe posts.

### Non-Goals

- Thirst-trap-first growth.
- Direct emotional monetization.
- Explicit or adult platform monetization.
- Fake luxury persona.
- Motivational influencer persona.
- Technical authority positioning.

## Operations Contract

### Current Operating Model

```text
manual-assisted semi-autonomous workflow
```

The console and n8n can create publication jobs, generate briefs, generate prompt packs, submit image generation, ingest Comfy outputs, and support asset review.

### Catalog Defaults

```text
avatar: estefania-montealegre
businessProfile: influencer-brand
assetType: raw-image
initialStatus: draft
```

### Current Systems

- n8n for workflows.
- Comfy Cloud for image generation.
- ai-gateway for Comfy API submission.
- MinIO for asset storage.
- PostgreSQL for catalogs and asset registry.
- Asset Review Dashboard for review and admin operations.

### Asset Policy

- Generated images enter as candidates.
- Human review selects, rejects, or promotes.
- Canonical assets are the official references for scene/avatar/asset grouping.
- `assetType` remains internally `raw-image` by default until there is a real operational need to expose multiple asset types.

### Review Flow

```text
create publication job
-> generate brief
-> generate prompt pack
-> generate images
-> ingest Comfy output
-> review candidates
-> promote/select/reject
-> create publication draft
-> manual approval/export
```
