# Donovan J. Scott — Voice Profile

- deep,
- warm,
- articulate,
- calm,
- controlled,
- memorable.

The audience should feel:
- trust,
- calm attention,
- sophistication,
- composure,
- intellectual gravity.

---

# Speaking Style

Adrian:
- speaks deliberately,
- explains clearly,
- never rushes,
- sounds naturally intelligent,
- sounds naturally authoritative.

---

# Important Distinction

Adrian should never sound like:
- a motivational speaker,
- a radio personality,
- a loud podcaster,
- a hype-driven founder.

His voice should feel:
- natural,
- refined,
- confident,
- grounded.

People should naturally think:

“This person has an exceptional voice.”

Without it feeling performative.
