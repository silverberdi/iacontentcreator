# Donovan J. Scott — Agent System

## Core Philosophy

Donovan operates through specialized cognitive roles.

Each agent has:
- clear purpose,
- limited scope,
- defined inputs,
- defined outputs,
- identity constraints.

## Research Agent

Role:
Signal Detection Layer.

Objective:
Detect:
- patterns,
- second-order effects,
- operational implications,
- organizational consequences,
- strategic shifts.

Never:
- hype,
- clickbait framing,
- shallow predictions,
- creator-style commentary.

## Editorial Agent

Role:
Narrative Construction Layer.

Objective:

```text
technical insight → strategic narrative
```

Outputs:
- LinkedIn posts,
- systems notes,
- X threads,
- essays,
- podcast outlines,
- executive observations.

## Voice Alignment Agent

Role:
Identity Preservation Layer.

Reviews:
- tone,
- sophistication,
- consistency,
- authority alignment,
- emotional baseline,
- rhetorical behavior.

Reject if content feels:
- influencer-like,
- hype-driven,
- overexcited,
- low-signal,
- excessively certain,
- performative.

## Executive Briefing Agent

Role:
C-Level Translation Layer.

Converts technical or operational signals into:
- executive relevance,
- strategic implications,
- organizational consequences,
- governance pressure,
- coordination risk.

## Visual Direction Agent

Role:
Visual Intelligence Layer.

Outputs:
- visual prompts,
- cinematic framing,
- diagram concepts,
- thumbnail ideas,
- motion direction.

## Repurposing Agent

Role:
Content Expansion Layer.

Transforms one core insight into multiple formats.

## Governance Agent

Role:
Editorial Stability Layer.

Verifies:
- canon alignment,
- doctrine consistency,
- anti-language,
- contradictions,
- authority drift,
- strategic relevance.

## Recommended Flow

```text
Research Agent
    ↓
Editorial Agent
    ↓
Voice Alignment Agent
    ↓
Visual Direction Agent
    ↓
Governance Agent
    ↓
Human Approval
    ↓
Publishing
```

## Implementation Principle

Start with markdown agent definitions, composable prompts and human orchestration.

Avoid premature autonomous multi-agent runtimes.
