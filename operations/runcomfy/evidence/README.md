# Evidencia de licencias

Guarda aquí evidencias que soporten la decisión de uso de cada recurso visual:

- texto de la licencia descargado desde la fuente;
- captura o exportación de los términos visibles;
- nota Markdown con fecha de verificación y fuente consultada;
- términos específicos de modelos, LoRAs o workflows.

## Convención de nombre

```text
<asset-id>/
├── source.md
├── license.txt
└── verification-notes.md
```

No guardes claves API, credenciales ni tokens en esta carpeta.
