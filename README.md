# IA Content Creator

AI-native multi-avatar content and publication system.

This repository contains:

- avatar canon and production assets,
- an admin/asset-review console,
- n8n workflow exports,
- an internal AI gateway,
- infrastructure notes,
- product strategy and backlog.

## Operating Principle

The project should not treat every avatar as the same product.

Business profile determines workflow, safety requirements, automation limits, review rules, and monetization path.
