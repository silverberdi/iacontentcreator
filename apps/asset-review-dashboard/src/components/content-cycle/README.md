# Content Cycle Status

This module is retired from primary dashboard navigation as part of the pre-video consolidation wave.

The official operator path for publication creation and generation is `Publications`.

Do not add new operator-facing behavior here. If a capability is still valuable, migrate it into:

- `Publications` for content generation and publication work.
- `Characters` for character/canon readiness work.
- `Ops / Admin` for technical diagnostics or maintenance.

This folder can be deleted after any remaining useful ideas are migrated and no workflows depend on it.
